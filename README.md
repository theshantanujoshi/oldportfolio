# Shantanu Joshi's Portfolio

A minimal, highly interactive social links landing page. Featuring automated multi-color iridescent liquid shader background effects, custom pointer pixel trails, responsive layouts, and brand-matching glows.

## Tech Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript
- 3D/Animations: Three.js, Postprocessing
- Icons: Feather Icons, Inline Custom SVGs
- Typography: Inter, JetBrains Mono (Google Fonts)

## Features
- **Fluid Interactive Background**: Custom Three.js pixel-blast iridescent fluid background.
- **Custom Cursor & Pixel Trails**: A responsive cursor tracking system with gravity-affected pixel dust trails on desktop and mobile drag/touch (background-only).
- **Responsive Adaptive Grids**: Specially configured layouts for desktop and mobile viewports with tailored order preferences.
- **Brand Glows**: Platform-specific dynamic shadow glows on button hover.
